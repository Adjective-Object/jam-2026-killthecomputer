# SETUP
- Install [`vscode`](https://code.visualstudio.com/download?_exp_download=d53503e735)
- Download and run the [dotnet](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/sdk-10.0.401-windows-x64-installer) installer ([windows link](https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.401/dotnet-sdk-10.0.401-win-x64.exe))
- Install [Godot Engine - .NET](https://godotengine.org/download/windows/)
- Install [the yarnspinner editor](https://yarnspinner.dev/editor/) within vscode:
    - Go to the [vscode marketplace page](https://marketplace.visualstudio.com/items?itemName=SecretLab.yarn-spinner)
    - Click "Install" (after installing vscode). You should be prompted to install the extension
